# Scusi? • Guida Corsie (Offline Ready & QR Share • v3.2.0)

Web App progressiva (PWA) progettata da **Massimo Maggipinto** per **Marco Campedelli** (2026), pensata come strumento di supporto interno per individuare rapidamente corsie e reparti su smartphone, tablet e desktop.

## Novità della Versione 3.2.0
- **Tasto `×` Liquid Glass Sempre Visibile nel Modale QR**: il pulsante di chiusura resta ancorato in alto a destra con effetto vetro traslucido anche scorrendo fino in fondo alle note legali.
- **Chiusura Automatica Tastiera Smartphone**: toccando qualsiasi area vuota dell'app (o scorrendo i risultati) la tastiera si chiude subito.
- **QR Code Condivisibile & Modalità Offline (`sw.js`)**: QR Code personalizzato Conad in prima posizione toccando **Scusi?** + caching locale completo di codice, loghi e illustrazioni.
