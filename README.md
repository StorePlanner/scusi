# Scusi? • Guida Corsie (Auto Dark Mode • Liquid Glass)

Web App progressiva (PWA) progettata da **Massimo Maggipinto** per **Marco Campedelli** (2026), pensata come strumento di supporto interno per individuare rapidamente corsie e reparti su smartphone, tablet e desktop.

## Novità della Versione 3.0.0
- **Interfaccia Pulita e Simmetrica**: rimosso ogni interruttore superfluo; il badge **Scusi? • GUIDA CORSIE** in alto è cliccabile per aprire le informazioni e le note legali.
- **Composizione Equilibrata**: la scheda *«Dove si trova?»* è ancorata in basso lasciando completamente visibile la Margherita Conad sfumata decentrata ad arte tra la barra di ricerca e il fondo.
- **Night Mode / Dark Mode 100% Automatica**: segue nativamente le impostazioni di sistema del dispositivo (`prefers-color-scheme: dark`) sia su mobile che su desktop.
- **Compatibilità Desktop Potenziata**: focus automatico della barra di ricerca, selezione rapida con il tasto `Invio` e ritorno immediato con `Esc`.
