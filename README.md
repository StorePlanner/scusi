# Scusi? • Guida Corsie (Beta Amatoriale)

Web App progressiva (PWA) progettata da **Massimo Maggipinto** per **Marco Campedelli** (2026), pensata come strumento di supporto interno per individuare rapidamente corsie e reparti.

## Contenuto del Pacchetto
- `index.html`, `style.css`, `script.js`: Applicazione completa con ricerca tollerante agli errori (*fuzzy*), sfondo dinamico a tutto schermo, titolo auto-adattante e modale informativo/legale.
- `conad-symbol.svg`, `conad-hero.png`: Asset grafici reperiti dal codice sorgente pubblico di `www.conad.it` e utilizzati esclusivamente a scopo descrittivo/illustrativo interno.
- `icon.svg`, `icon-192.png`, `icon-512.png`, `manifest.json`: Set di icone e manifest PWA per installazione su Home Screen (iOS/Android).
