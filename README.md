# Scusi? • Guida Corsie (Offline Ready & Visual Install • v3.4.0)

Web App progressiva (PWA) progettata da **Massimo Maggipinto** per **Marco Campedelli** (2026), pensata come strumento di supporto interno per individuare rapidamente corsie e reparti su smartphone, tablet e desktop.

## Novità della Versione 3.4.0
- **Percorso Visuale iPhone a 3 Step**: istruzioni grafiche fedeli alle icone di Safari (**1. Le 3 linee** → **2. Condividi** → **3. Aggiungi alla schermata Home**) sia nel banner inferiore sia nella scheda QR Code.
- **QR Code Condivisibile & Tasto `×` Liquid Glass Fisso**: toccando **Scusi?** in alto si apre subito il QR Code personalizzato Conad (`qr-scusi.png`), con chiusura sempre visibile in alto a destra.
- **Chiusura Automatica Tastiera & Modalità Offline (`sw.js`)**: la tastiera sparisce toccando qualsiasi area vuota e l'app funziona interamente offline anche nelle corsie senza segnale.
